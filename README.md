# 🐍 Tricolor Snake Game

A classic 2D Snake game developed in Java with a theme inspired by Grêmio.

## 🎮 Features

- Classic Snake gameplay
- Grêmio-inspired color palette
- Random food generation
- Score counter
- Collision detection (walls and snake body)
- Game Over screen
- Press **ENTER** to restart the game

## 🛠️ Technologies

- Java
- Java Swing (GUI)
- AWT

## 🎯 Controls

| Key | Action |
|------|--------|
| W | Move Up |
| A | Move Left |
| S | Move Down |
| D | Move Right |
| ENTER | Restart after Game Over |

## 📁 Project Structure

```
src/
├── Main.java         // Creates the game window
└── GamePanel.java    // Game logic, rendering, controls and collision system
```

## ▶️ Running the Project

1. Clone the repository:

```bash
git clone https://github.com/your-username/tricolor-snake-game.git
```

2. Open the project in your preferred Java IDE (IntelliJ IDEA, Eclipse or NetBeans).

3. Run `Main.java`.
